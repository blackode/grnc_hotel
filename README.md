# GrncHotel

Elixir Developer Coding Test

Welcome to the Elixir Coding Assessment. This test evaluates your skills in Phoenix, Ecto, modular design, API development, and problem-solving.

Please follow all steps carefully and ensure your code is clean, documented, and tested where applicable.

---

### 🚀 Project Setup

You will be given access to a GitHub repository containing a Phoenix project template.

1. Clone the repository

   ```
   git clone `https://github.com/blackode/grnc_hotel`
   ```

2. Install dependencies

   ```
   mix deps.get
   ```

3. Setup the database

   ```
   mix ecto.setup
   ```

This should automatically run migrations and seed initial data.

4. Verify seeds by running:

   ```
   mix run priv/repo/seeds.exs
   ```

### NOTES

Ensure the project compiles and runs before proceeding.

---

To start your Phoenix server:

- Run `mix setup` to install and setup dependencies
- Start Phoenix endpoint with `mix phx.server` or inside IEx with `iex -S mix phx.server`

Now you can visit [`localhost:4000`](http://localhost:4000) from your browser.
